# 技能五子棋

一个用于 Git 和 GitHub 实战带练的原生前端小游戏项目，主题为赛博霓虹风格的技能五子棋。

## 当前功能

- 15x15 棋盘
- 本地双人轮流落子
- 五连判胜
- 3 连触发小技能，4 连触发大技能
- 首版技能：封锁、冲击、爆破、转化
- 战斗日志、胜负弹层、最近一步高亮
- 玩家 vs AI 模式、难度档位、思考遮罩
- 盘面统计（黑 / 白 / 空子数）与键盘快捷键（N/U/S/Esc）
- 预留后续可接 DeepSeek 等外部决策接口

## 技能规则

- 新形成 3 连：可在本回合释放一个小技能
- 新形成 4 连：可在本回合释放一个大技能
- 每回合最多触发 1 次技能
- 技能造成的盘面变化不会在本回合直接判胜

## 技术栈

- HTML
- CSS
- JavaScript
